# Awesome Apify Actors [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of public [Apify Actors](https://apify.com/actors) — ready-to-run web automation and scraping tools that you can call as APIs.

[Apify](https://apify.com) is a cloud platform for running web scrapers and automation jobs (called "Actors"). Each Actor exposes a JSON-input API, runs on Apify's compute, and writes results to a dataset. Pricing is pay-per-compute-unit (or pay-per-result for many actors).

This list covers public Actors with significant production usage. Run counts are pulled from the [Apify Store API](https://api.apify.com/v2/store) and reflect cumulative lifetime runs across all users.

## How to add an Actor

To submit an Actor for this list, open a pull request with:

1. A public Apify Store URL (the Actor must be runnable by anyone — not a private Actor)
2. A one-line description focused on what it does, not marketing copy
3. A category placement (or propose a new category if none fit)
4. Run count from the Apify Store API (helps future readers gauge maturity)

Strongly preferred: the Actor has at least **10,000 lifetime runs**, an MIT or permissive open-source license (when source is available), and a clear input schema.

Subjective tiebreaker: when two Actors do the same thing, the one with cleaner OAuth handling, lower error rates in cold-start runs, and a published `INPUT_SCHEMA.json` wins.
